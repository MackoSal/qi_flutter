# Figma Setup

Use Figma as the design source for collaborative product design.

Figma is a cloud-based design tool. Unlike Penpot, you do not need to self-host it.

## Integrations

When using Figma, you can export design tokens using community plugins (like Design Tokens or Figma Tokens) and convert them to Flutter styles.

If you decide to use Figma instead of Penpot, you can safely delete the `design/penpot` folder. Alternatively, you can mix both tools depending on the team's preference.
