# Security policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues. Use GitHub's **Report a vulnerability** feature on the repository's Security tab to send a private report to the maintainers. Include the affected version or commit, impact, and reproduction steps when possible.

## Supported versions

The latest `master` branch is the only maintained version of this template. Projects generated from the template are maintained by their respective owners.

Do not commit credentials, signing keys, access tokens, or private application data. Configure release secrets in the GitHub repository settings.
